## Olá, seja bem vindo ao meu projeto!

Esse projeto foi desenvolvido na aula com o Sujeito Programador, onde absorvi uma grande quantidade de conteúdo excepcional na qual agregou muito em meu conhecimento.

Nele, foi utilizado as seguintes tecnologias:

-Next\
-React\
-Sass

Não foi utilizado nenhuma biblioteca, a streaming UI foi feita com CSS puro, como utilizo o Next, existe o componente <Suspense/> com fallback na qual lida com carregamento.\
Espero que tenha gostado.
